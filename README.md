# qa_python
0. Удален тест-пример, т.к. он использует метод get_books_rating, не описанный в main. 
Согласовано с наставником в YM.
1-2. test_add_new_book_add_two_books_check_if_name_valid - параметризированный тест, принимает на вход названия книг и признак валидности названия.
Проверяет, что валидное имя добавляется в словарь books_genre, невалидное (>40 символов) - не добавляется. 
Assert сравнивает факт добавления книги с признаком валидности ее имени.
3. test_add_new_book_add_book_twice_book_not_added - пробует добавить в словарь books_genre 4 книги, одну из них повторно. 
Проверяет, что добавилось только 3
4-5. test_set_book_genre_validate_genre - параметризированный тест. Принимает на вход два жанра, один из списка genre, второй - нет, 
а также ожидаемый результат их добавления. Проверяет, что в первом случае жанр проставляется, во втором - остается ''.
Также проверяет работу метода get_book_genre
6. test_get_books_with_specific_genre_filtered_names_returned - создает три книги с жанрами, проверяет что метод возвращает список, 
отфильтрованный по выбранному жанру.
7. test_get_books_genre_full_dictionary_returned - заполняет словарь тремя валидными книгами, проверяет, что метод возвращает словарь целиком и без ошибок
8. test_get_books_for_children_filtered_out_rated_and_unknown - заполняет словарь пятью книгами. Проверяет, что метод возвращает список, в который не 
входят фильмы с жанром с установленным возрастным рейтингом и с жанром не из списка жанров.
9. test_add_list_of_books_in_favorites_only_allowed_book_added - пробует добавить в список favorites три книги: валидную, её же повторно и недобавленную в словарь книгу.
Проверяет, что в итоге в списке получается только один элемент. Дополнительно проверяет метод get_list_of_favorites_books
10. test_delete_book_from_favorites_book_deleted - Добавляет две вниги в favorites. Проверяет удаление валидной книги из favorites, 
а также попытку удалить книгу не из словаря и не из favorites. Убеждается, что в favorites осталась только одна книга.
Дополнительно проверяет метод get_list_of_favorites_books
11. test_get_book_genre_genre_returned - прямая позитивная проверка метода get_book_genre
12. test_get_list_of_favorites_books_favorites_returned - прямая позитивная проверка метода get_list_of_favorites_books
